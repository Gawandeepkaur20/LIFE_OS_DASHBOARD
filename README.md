## 📖 Overview

Life-OS is an AI-powered digital wellbeing dashboard built during the **MirAI School of Technology – AI Builder Internship**.

The application visualizes daily screen-time habits, analyzes productivity, generates personalized AI wellness reports, and helps users develop healthier digital routines through actionable insights.

## 🚀 Installation

Clone the repository

```bash
git clone [https://github.com/YOUR_USERNAME/Life-OS.git](https://github.com/Gawandeepkaur20/LIFE_OS_DASHBOARD)
```

Move into the project

```bash
cd Life-OS
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=your_api_key
```

Run the application

```bash
streamlit run app.py
```
